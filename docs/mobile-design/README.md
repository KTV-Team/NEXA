# Mẫu duyệt UI/UX

Các HTML/CSS trong thư mục chỉ dùng để trao đổi và chốt giao diện. Xem [mục lục mẫu](index.html).

Nội dung, dữ liệu minh họa, tên/số màn, menu và thao tác trong mẫu không phải yêu cầu sản phẩm, API, data model, roadmap hay bằng chứng tính năng đã triển khai.

Nguồn yêu cầu là task brief người dùng đã cung cấp và các xác nhận trực tiếp. [PRD](../product-requirements.md) ghi lại yêu cầu; [hướng dẫn duyệt UI](../mobile-ui-ux-plan.md) giải thích cách sử dụng mẫu.
